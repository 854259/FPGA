## 契约规定

**请求**（`API_CONTRACT.md` L80-88）：

```json
{
  "task_id":    "eval-0007",
  "nonce":      "T042-eval-0007-3-1763251200123456789",
  "mode":       "agent",
  "prompt":     "…",
  "interface":  "…",
  "deadline_s": 360
}
```

**响应**（L93-100）：

```json
{ "task_id": …, "solution": …, "trace": …, "elapsed_s": … }
```

**关键约定**：
- L108：`interface` **在评测题集下为空串**
- L110：`solution` **做不出来返回空字符串，不要报错**
- L104：`task_id` **返回时必须原样带回**

## 三条最容易踩的边界，逐条确认

1. **`interface` 为空串**（评测题集的实际情况）
   → `solve()` 用 `if data.get('interface')` 判断，空串不写文件。**实测 200 且正常出解。**
2. **响应字段集合**
   → **实测恰好是契约的四个字段**，没有多余字段，也没有缺字段。
3. **极小 deadline**
   → 返回 `200` + `solution: ''`。**契约明确要求"不要报错"**，这一条做到了。
