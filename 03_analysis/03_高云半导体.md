# 高云半导体赛题摘要

来源：`01_sources/pdf/高云半导体.pdf`；全文：`02_extracted/pdf_text/高云半导体.txt`。

## 平台

- J280 姿态控制竞赛套件：FPGA 控制板、角位移传感器、电机编码器和倒立摆机构。
- Sipeed Tang Nano 20K / Primer 25K / Mega 60K / 138K。
- 小梅哥 ACG720、ACG750、BX72、ACG138-RK3588 等视觉/异构平台。
- 允许自备以高云 FPGA 为核心的第三方板卡。

## 题目

1. **实时姿态控制**（PDF 文件页 14）：自动起摆、自平衡、长期稳定、抗轻推；扩展为位置/轨迹控制。套件降低搭建成本，但不降低控制与调参本质难度。当前新手风险高。
2. **实时多音色合成电子乐器**（页 15–16）：至少 2 个交互维度、纯 HDL 逐样本合成、总延迟 ≤10ms、≥4 复音、I2S/DAC；高阶含 ≥32 复音、效果器与可视化。新手风险中偏高。
3. **具身智能机器人**（页 17–19）：摄像头、IMU、闭环运动、避障和自主导航为基础，AI 识别是拓展。新手风险很高。
4. **开放型**（页 20）：必须突出 FPGA 主体地位，明确不使用 MCU。适合已有创意与积累者。

## 板卡与支持

- 指南称每队可申请一块板，评审后抽取寄送，完赛后寄回。
- 板卡申请、Tang 资料与指导群见 `02_extracted/RESOURCE_LINKS.md`。

## 当前判断

倒立摆的演示闭环清晰、硬件套件完整，但连续域不稳定对象和现场调参对零基础团队非常不友好。除非至少一人已有控制理论、电机驱动和示波器调试经验，否则不进入前三短名单。
