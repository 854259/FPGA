## 7. 方法论警告：本底噪声

baseline **不读 skill**，所以它的成绩本应逐题不变，但实测 **5/156 题（3.2%）发生翻转**：

| 题目 | 旧 baseline | 新 baseline |
|---|---:|---:|
| Prob086_lfsr5 | 0.00 | 1.00 |
| Prob100_fsm3comb | 0.00 | 1.00 |
| Prob103_circuit2 | 0.20 | 1.00 |
| Prob133_2014_q3fsm | 0.20 | 0.00 |
| Prob140_fsm_hdlc | 0.20 | 0.00 |

**原因（A 分析判断）**：`-t 8` 多线程下浮点归约顺序不固定，temperature 0 仍有约 3% 的单题翻转率。

**后果**：26 道 agent 变化中约 5 道可能来自噪声。因此

- **±1 题的差异不构成结论**；本报告的判读建立在"净 +6 题 / 增益 +0.024 / 配对净 +15→+20"这些量级上
- 后续任何 ±1 题的改进宣称都需要多样本或重复运行支撑
- 若要严格归因，需引入多 seed 或 5 样本协议

## 8. 结论

1. **精简规则是明确的净改善**：能力 +1.00、增益 +0.024、能力+增益 **+1.96**，且配对指标上改进更多、退步更少。
2. **删规则 8–11 的方向得到验证**——09-14 A/B 的结论（11 规则是负优化）在今天的流水线上复现。
3. **仍有 2 道模型无关回归未解决**（Prob150 状态自环、Prob154 数据通路覆盖），是下一轮的靶子。
4. **skill 应保持精简**。后续改进要先证明必要性再增加文本——本次证据表明冗长的规则文本本身有害。
