# H1 连续实验计划：题集合同与完整流程风险

用户已要求细化并开始下一步。本批内部硬上限9次新增模型调用、2700秒AMD实验时间，模型和最佳runtime沿用G1；不自动补足用量、不复用旧批次预算名义。

1. **先修输入版本，0模型调用。** 对已冻结44题的220文件校验旧manifest。复用已有ef72fc6的load_prompt；只去掉旧转换器补出的确定性前缀，再规范原模块名标签。验证23题仅名字变化、21题字节不变；所有原件保留。静态检查参考与候选入口端口及TB连接，无法证明的语义标为待审，不称44题有效。
2. **语义准入，0模型调用。** 固定选择adder_bcd和barrel_shifter，未用它们调整当前提取规则。按题面而非模型结果，分别穷举200个合法BCD输入和2048个移位输入；验证参考与独立算术表达式一致。另用评测侧单输出反相负控，必须全部检出；正控须L3。BCD旧随机激励可能超出0–9输入域，新版本只改变该评测范围和移位覆盖，不改模型题意。
3. **先查已知风险，最多2新调用。** 复用F1已捕获的32位首次回复，原版、新版各保留一次条件修复。旧题面、旧评测输入不改，避免把题面修正混入提取器比较。记录原版是否恢复而新版因跳过修复退化；发生退化立即拒绝当前自动提取并取消后两对生成。
4. **条件衔接，最多6新调用。** 前两门通过且风险对照未观察到退化，再按BCD、移位的固定顺序各跑一对。共享首次真实回复，各臂保留原版一次修复；原版最多2调用，新版最多1额外调用。两臂完成求解后才进入参考/TB评分。首次回复复用不算免费生成时间，逻辑调用与实际调用分报。
5. **自动收尾。** 输出各题等级、修复/改坏/不变、错误与回退、实际/逻辑调用、求解与完整阶段耗时、保护文件和进程清理证据。命中错误/超时不补抽，不更换失败题，不在本批根据结果改规则。归档私有原始证据，公版JSON/报告同步研究分支，正式部署不变。
