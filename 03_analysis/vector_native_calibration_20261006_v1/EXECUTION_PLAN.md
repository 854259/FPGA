## 1. 复用已有证据，确认本因素边界

先读取团队当前工作、实验登记与已审计结果。待 FIFO80 的 780 行评估取得真实终态并完整读回后，复用队友既有统计工具、完整档案和审计出口。使用完整身份、源文件哈希及原审计绑定判断哪些题当前正确、哪些错误或不稳定；不把阶段计数、summary 或不同版本的局部结果拼成终态。不重做同功能收尾，也不重复 80／83／84 的原冻结任务。

此因素只加入严格的题面／接口向量数据流机械生成入口。生产路径依据语义契约选择生成或弃权，不接收实验题号名单，不缓存答案，不从 judge、官方 TB、参考 RTL 或旧候选构造契约。原模型 fallback、调用预算、一次修复规则与完整原判定保持原方案；其他表格、FSM、专家技能和知识库因素不混入本次对照。

三组必要检查成功后，一次 prepare 已实际完成 27 个控制、81 个资产及 7943 条独立 literal 期望（二进制 3993、四态数据传递 3950），配方计数、源字节和反例绑定已由根代理物理读回。期望条数不是已观测原生轨迹数。准备实际模型／EDA 调用为 0，原 judge 未执行；prepare 自身不创建 RUN_SPEC，也不自动获得资源或入队。已存在目录和回执继续保持一次性语义，通过读回恢复状态，不能重复测试或覆盖证据。

## 3. 独立审查、冻结与原生校准

根代理已在 AMD 完成实际环境、工具／Python 身份及保护组验证，冻结执行源码、六输入、准备资产、CASE_PLAN、依赖和回执共 140 文件。冻结准入及编译环境验证通过；捕获的 18 组既有源共 930 资产保持，源与共享模型身份在物理读回中未变。冻结后仍未入队、未运行原生工具、未建立原生资格。后续 FIFO 票号与进程归属必须来自实际状态，不能为本计划编造票号；冻结和 PR 合并都不部署。

固定校准是 **planned 27 控制、72 原生命令＋2 监督命令、150 guard 回执、7943 观测**。两域计划分别为二进制 3993、四态数据传递 3950，模型请求为 0。每个固定控制只执行一次，不补抽、挑选或重采样。真实命令、返回码、原样日志、源／TB 前后 SHA、时钟、父子进程清理与每次 guard 均须完整保留；失败和部分轨迹按实际计数报告。

正控制、负控制、传输拒绝、EDA 失败和监督探针分别审计。实际环境／监督失败不能算语义负控制成功；显示 fatal 标记不能替代实际 fatal 输出；阶段上报的 native_qualified 不能自动升级为已审计资格。`evidence_complete` 与 `native_qualified` 分开，只有固定矩阵的完整原始档案独立审计通过才获得本校准的有限原生资格。

本校准只规定二进制选择器和其下的数据 x/z 传递义务，数据刺激是有限集合。原 judge 的选择器 x/z 检查范围不在此推断，后续原 judge 始终完整不变。即使校准合格，也不能据此宣称原题分数提高、隐藏题通过、模型能力提升或生产采用。

## 4. 未来固定六题、十二行 C/P 单因素试验

原生资格与全部前置回执取得后，根代理才冻结以下固定元数据名单。当前未冻结、未入队、未执行；名单仅用于实验编排，不进入生产生成器。

| 角色 | 固定题目 | 主要验证目的 |
| --- | --- | --- |
| 提分目标 | Prob064_vector3、Prob097_mux9to1v | 原完整判定下是否取得目标净增 |
| 回归守护 | Prob017_mux2to1v、Prob042_vector4 | 当前正确行为及严格弃权后 fallback 是否保留 |
| 保守边界 | Prob062_bugs_mux2、Prob104_mt2015_muxdff | 模糊错误修复、时序／层次题面继续弃权，不扩大语法 |

六题各跑一次 C 和一次 P，共固定 **12 行**。C 使用审计绑定的原基线，P 只增加本向量机械生成因素；同一模型、原 prompt/interface、原 harness、原 judge 和判定工具均保持绑定。每行维持原 **8192** token 预算、最多 **2** 次模型调用、最多一次原修复，以及 **300 秒绝对时限**，不因机械路径、排队或失败重置预算。

机械生成行必须精确绑定原输入、生成 receipt、RTL 与生产源哈希，实际模型 requests 为零；弃权行仍走原模型 fallback，按真实请求／响应与工具证据计数。不把 0 模型机械行记成模型作答，也不为缺失、超时、未确认或监督失败的行补测。完整 12 行全部保留并独立审计。

进入下一阶段的门槛同时包括：

- 至少一个目标题取得原判定下的新增 L3，目标 L3 净增至少 1；报告 paired 结果及审计绑定的当前基线，不能仅把基线波动当成已证实收益。
- 所有当前正确题均无回归；固定回归守护保持原正确等级，保守边界不因扩语法或换流程获得混合因素结果。
- 完整十二行不存在 deadline、tool／supervision、source／环境、未确认请求或证据缺失失败。
- P 的实际模型调用总数不高于 C；守护／fallback 的调用成本不增加，token 和绝对时间上限保持原预算。完整报告各行及总调用、token、工具与耗时，不能仅挑得分行宣称无成本增加。

只有完整固定试验与独立审计同时过门，才说明该固定小试支持继续评估；它仍不证明全量或隐藏题收益。任一门失败，记录实际失败及反例，保持原已采用版本，先分析后设计明确的新版本，不在原冻结名单内补抽或重跑。
