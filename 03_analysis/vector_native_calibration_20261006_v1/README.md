# 向量数据流单因素：原生校准准备

本目录公开说明一个独立的向量数据流因素及其验证计划。目标是检查：仅从完整原题面和接口机械生成的拼接／拆分与选择器逻辑，能否在保持原判定不变的条件下提高作对题目的能力。本次文档编写只做静态编辑，不执行技能接入、模型、EDA 或断网任务。本记录尚未建立原生资格或分数收益。

源码准备账本 `SOURCE_LEDGER.json` 的精确 SHA-256 为
`41bc2f5de5fd3d967e5048ff4053c6e5f522bf878a9e6ce5ecb93cefa80cca45`。
该账本绑定 10 份私有准备文件和原六输入文件；它是静态准备记录，不是 RUN_SPEC、执行回执或通过证明。私有 sources、独立 recipe、原 prompt/interface、生成 RTL、TB、逐条观测及原始输出均排除在公开交付之外。公开结论只能引用经审查的哈希、计数、状态与判定摘要。

计划原生命令为 xvlog 25、xelab 24、xsim 23，共 **72**；另有 **2** 次自有监督命令，共 74 次受监督调用和 **150** 份资源／源文件 guard 回执。计划完整轨迹为 **7943** 条观测，其中二进制 3993 条、四态数据传递 3950 条。计划模型请求为 0。这些数量不能代替实际启动、完成、输出、失败或清理证据。

此次校准枚举每个案例的完整二进制选择器域，并使用固定的有限数据刺激。数据 x/z 单独检查在二进制选择器下的位传递；不为选择器 x/z 创造题面未规定的期望。校准范围是有限且有边界的，既不是全部数据组合的穷举，也不能据此宣称原判定排除 x/z。后续完整原 judge 必须保持原字节、原工具和原判定流程，不删减或筛选其中的任何检查。

正控制需要完整实际轨迹、正常工具退出、精确 DONE／唯一 PASS 和前后源文件一致。语义负控制需要在预先绑定的反例观测上出现实际失配，并正常完成完整轨迹；编译错误、超时和启动错误不能替代语义失败。PASS 后 fatal、缺少／重复／错误计数 PASS、源突变以及父子进程清理均有独立拒绝义务。阶段 summary 中的资格字段不能替代完整档案审计。

原生阶段计划 cap 为 2400 秒，每条原生命令 30 秒，每个监督探针 0.8 秒；外层 guard 2600 秒，整任务 FIFO slot 45 分钟。这些是固定上限，不是已测运行时长。所有实际项目执行仅在授权 AMD 服务器进行，使用独立私有目录、精确源文件与工具哈希以及自有 FIFO／资源归属。任何失败或部分证据均保留，不重采样补齐，也不接管队友任务。
