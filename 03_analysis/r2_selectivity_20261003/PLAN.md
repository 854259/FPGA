# R2b 选择性与正常实现保护：执行前设计

本轮仅验证离线选择器、人工构造边界与五道已有归档守卫，不调用模型、不改部署，不测全量成绩。另行保存的086移位边界探针属于不同假设。

- 输入仅题面和候选源码；选择器不接受题号、历史等级、官方测试台或参考实现。输出review/skip/abstain只是是否有足够证据建议复查，skip不是正确性证明。
- 范围有意收窄为题面明确算术右移且能可靠归属到输出状态寄存器的简单无符号`>>>`；复杂类型、预处理、混合/否定规格、无法归属的内部移位等弃权。只生成建议，不自动补丁。
- 固定五守卫：033、016、009、085、123，按前轮NEXT_CANDIDATES的原字节和哈希；每题先正控制通过、负控制完成仿真且失配，再验证归档候选。任何不一致保存原始失败，不修题面/候选去迎合结果。
- 人工语义边界：变宽/改名的无符号状态、合法signed/显式转换/拼接、逻辑右移、正确复合表达式、无关内部移位、signed切片、宏、注释字符串等。全部为构造控制，不冒充独立新题或自然错误。功能预期由独立整数oracle验证，选择器期望同时冻结在fixtures/manifest.json；有错即修选择器并保留失败记录，再完整重验。
- 实验门槛：已定义支持范围的错误应review；全部已验证正确的人工候选和五真实守卫不得review；范围外真实错误允许abstain但必须单列，不能宣称检出率100%。正负控制无效或环境错误不得算检测通过。
- 原156候选只做离线扫描，报告三态分布、耗时、源码哈希和每项理由，不据静态结果给155个未命中标正确；不把这一轮当成repair模型效果或泛化验证。
- 选择器达到上述门槛，只允许进入隔离的运行时集成评估；不追加无预算模型调用，不更改现行runtime/skill，不宣布正式版本通过。
