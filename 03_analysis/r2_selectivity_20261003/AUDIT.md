# 独立只读复核

未操作云端的复核代理从原始产物重新核验，而不是只读取valid字段：

- 265个归档文件的SHA/字节数、81个冻结源码hash、36份实际DUT/TB对指定源文件全部匹配。
- 108段日志hash/字节数匹配，全部阶段rc=0，无超时、启动错误或进程组终止。逐日志解析唯一完成行：36份共592,374次比较，21份通过、15份预期语义失败；无环境失败。
- 使用归档选择器重新分析12个固定案例，分类及理由完全相同。实际错误5个，仅2个review，另3个abstain；7个正确候选没有review。
- 五守卫正对照、归档候选均零失配，负对照数32512/120/4/40/255与独立枚举吻合。
- LFSR另以整数状态机重放得到269检查/220失配；check7 step3首次01010/11010，step1是额外reset，故为第二个非reset有效沿。

复核没有改变原始文件或追加模型/云端判定。静态原型和题面语义得到有范围的证据，不能据此声称模型会修好、正式评分提高或未见题泛化。
