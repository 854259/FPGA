# R2 选择性验证：五个题面守卫

这些材料来自已使用过的开发来源，不能称独立验证集。仅阅读原始题面与归档候选源码，未读取官方测试台、参考实现或 verdict；未调用模型。原件逐字节保存在各题 `prompt.txt`、`candidate.sv`，原始路径与 SHA-256 见 `provenance.json`。

| 题目 | 每次检查数 | 正对照 | 负对照 |
|---|---:|---|---|
| Prob033_ece241_2014_q1c | 65,536 | 扩展到 9-bit 的有符号和及符号位比较 | 以 unsigned carry 冒充 signed overflow |
| Prob016_m2014_q4j | 256 | 四个显式全加器与逐级进位 | 截掉最高进位 |
| Prob009_popcount3 | 8 | 全部输入的独立真值表 | 仅保留奇偶位 |
| Prob085_shift4 | 209 | 异步复位、同步加载、逻辑右移 | 错误符号填充 |
| Prob123_bugs_addsubz | 131,072 | 8-bit 加减结果及其零标志 | 以 9-bit 未截断结果判断零 |

组合逻辑用独立整数运算穷举；033 将输入手工解释为 −128…127 的数学整数，123 在整数运算后取模 256。085 在时钟低电平驱动输入并在非阻塞赋值后取样，先复位再读取，遍历 16 个装载值与五次右移，并覆盖加载优先、保持、非时钟沿异步复位、复位高电平与加载/使能竞争、释放复位不加载。共 209 次检查，不依赖未规定初值。

016 功能探针不能证明实现结构；手写正对照明确使用四个全加器，归档候选逐位实现全加器逻辑。本目录不会用功能通过冒充结构约束已被自动证明。

`probe_runner.py` 是薄包装，动态导入未修改的 R2 执行器，保留其独立进程组、阶段超时、启动/许可/协议错误与真实语义失败区分。每个 `result.json` 中 `runner_sha256` 为本包装哈希；总验证另记录继承执行器完整哈希，并将两者与所有输入/TB/控制纳入前后哈希核对。

运行需要 Linux 上已有 Vivado 工具与有效许可证。默认按兄弟分析目录定位 R2 原执行器；若云端位置不同，设置 `R2_BASE_PROBE_RUNNER` 为原 `03_analysis/r2_signedness_20261003/probes/probe_runner.py` 的绝对路径。

```
python3 -B /absolute/path/guards/probe_runner.py validate-guards --out /new/unique/output
```

固定执行五题的正对照、负对照、归档候选，共 15 次 EDA。每题必须正对照通过、负对照完成仿真且语义失配、原归档候选通过，全部文件哈希保持不变；否则 `guards_validation.json` 的 `valid=false` 且退出码 1。负对照编译失败不能算有效探针。既有输出目录不覆盖、不续跑；任何归档候选异常保留并报告，不修改候选来迎合探针。
