尚未发布的M和Tref不阻塞研发：固定同轮基线后，能力均值与增益比越高、实际求解耗时越少，评分方向就越有利。能力提升伴随更高耗时的方案要保留取舍证据，不能用占位参数冒充最终排名。当前优先完成队友132全量对照，并根据131失败记录准备候选源码结构错误定位反馈，保持当前试验预算，不重复零收益原配置。131另一类失败是在首修复后才暴露新反例，不能假称它已经提供给模型；有限额外修复只能作为另行登记的预算因素，尚不执行。请求次数用于成本诊断，不能代替官方墙钟得分。工程材料随真实改动更新，不把文档或检查数量算作能力提升。
