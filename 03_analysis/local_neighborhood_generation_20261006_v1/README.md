已准入的三题为 108、124、144；题号只用于实验结果登记，生产路径不按题号、输入哈希、规则名称或旧答案查表。它从完整文本中解析合法角色和尺寸、完整的局部二进制表或邻居数量规则；不完整、冲突或额外要求均弃权。可选接口不存在与存在但为空须按实际文件记录区分，本轮原输入没有接口文件，空字符串参数不冒称文件曾存在。

108 的显式 XOR 要求不依赖中心位，是已有正确题的守护案例；历史原判定为 L3、0／7121 失配。124 历史 L1、6220／6283 失配，方向颠倒的机制已由根代理原资料对照确认；新方向按题面数值关系保留：Left 来自高一位，Right 来自低一位。144 历史 L0 的真实编译收据确认常量索引位置使用变量；新生成器使用展开时常量目的索引、四位邻居计数和统一旧状态更新，同步加载优先。历史机制证据说明旧失败原因；新的纯生成结果尚不能证明新 RTL 已在真实工具中修复这些问题。

二维行切片支持行优先布局，但行内列方向是推断；完整对称 Moore 邻域环面在统一列镜像下等价。一般二进制表和计数规则没有额外规定四态语义；108 的显式 XOR 中心独立义务须单独实测。不能把有界二进制校准当作原 judge 排除 x/z 的证明。原完整 judge 必须保留原字节、工具和判定流程。

此前已审开发集结果仍为 **113／156 全对、77.4359% 加权分**，当前目标为至少 120 题全对且加权分至少 80%。本方向最多覆盖两个现有错误目标；假设两题都改善，加权增量的数学上界约为 **1.1538 个百分点**，全对题数最多增加到 115。这个上界不是预测或实测收益，也不足以单独完成总目标。
