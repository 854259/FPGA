# 原模块双输出异步复位契约：可编辑草稿

仅新增本目录。`native_reset_contract.py` 的直接函数为 `parse(prompt)`、`render_tb(contract, run_id)`、`observations(log, contract, run_id)` 和 `counterexample(log, contract, run_id)`；不读取任务 ID、context、hidden harness 或答案，不修改模块名，不调用框架、模型或 EDA。

题面来源为已核对 SHA 的原 JSONL，仅提取被指定记录的 public `input.prompt`。完整原题面、生成 TB、合成完整记录及逐控制完整解析反例均在被全局忽略的 `raw_evidence/`，未复制进公开源码或本文。原 prompt 的模块名代码标记前有未闭合双引号；仅保留这一原有配对代码标记形式及其改名变体，其他坏引号/标记弃权。

支持完整标量数据、上升沿时钟、低有效异步复位清零双输出与历史状态、分别一周期高有效的正/负边沿输出。按语义识别改名端口与模块，保留大小写；输入/输出条目及两条行为可换序。模块名可与任一合法端口名相同，不额外收缩原规格。重复/保留字/向量端口、改名后旧引用、缺句、额外行为、否定或冲突语义弃权。语法仍限定此完整描述和少量等义排版，不宣称任意自然语言覆盖。

生成测试台有 **69 个完整观察点，每点保留两个输出，共 138 个实际值**。纯序列检查确认 **19 次数据赋值、12 次值变化均在时钟低时**，合成完整解析逐点保留两个实际值。三次释放复位均先置零并检查两个上升沿预热。12 个变化/保持周期分别检查变化后、上升沿后、下降沿后。还分别在正脉冲和负脉冲仍高而时钟保持低时断言复位，并从已存高输入复位后以零释放，期间没有复位态时钟沿，防止只同步清历史状态误通过。未要求高输入首次复位释放的歧义行为。

本机 Python **3.12.14：35 个测试方法、242 个子检查，0 失败、0 错误**，准确收据见 `LOCAL_CHECKS.json`。一个合成正确记录通过；11 类合成负控制全部检出：忽略复位、同步复位、历史仅同步清除、只清正输出、只清负输出、输出互换、恒零、恒一、两周期脉冲、半周期脉冲、下降沿采样。另两类 X/Z 控制各保留一个真实字符失配。缺/重/乱序观察、错误期望/元数据、超宽值、伪造首点/结果、错 prompt/run 绑定、截断和类型变更均拒绝。首次纯检查中一个测试对忽略复位的首失配位置期望错误；已改用同步复位控制验证运行期场景，原失败收据保留于私有原始证据。
