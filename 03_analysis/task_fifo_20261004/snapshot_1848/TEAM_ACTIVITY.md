# 共享测试与修改台账

当前我们的台账：`/workspace/team/activity/fpga_owner/STATUS.md`，每30秒由只读观察程序更新。

调用元数据：calls.jsonl；修改与提交：changes.jsonl；结果、范围和未完成项：conclusions.jsonl。原始模型正文／测试证据保留在各自运行目录，不复制到摘要。已有日志回填的时间记为观察时间，不冒充原始调用时刻。

整任务FIFO入口与使用约定：`/workspace/team/TASK_FIFO.md`。从统一入口提交的任务按票号整项执行；旧直接入口尚需发起方迁移。
