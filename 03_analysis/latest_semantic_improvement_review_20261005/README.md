# 当前 39 个 L1 样本的语义复盘

只读核对最新全量 P 的 39 个 L1；原始 156 题中 113 个 L3、39 个 L1、4 个 L0，加权单样本分数仍为 77.44%。未新增模型、Vivado、SSH、FIFO 调用，也未重新运行冻结审计器。原包 10,785 个清单成员、44 份冻结源码及 600 个提取成员逐 SHA 一致；未把当前已通过的 143 算作失败。

最值得单独试验的下一项是生成前的逐边沿状态语义核对提示。8 个当前 L1（089、111、133、139、146、149、150、154）有题面和最终 RTL 可直接支持的偏差，覆盖 Moore 输出、连续窗口、序列识别、串行采样、历史保留、next-state 自环和消息边界。现有技能只有“逐拍一致”的总体要求，尚未把边沿前状态、输入采样、边沿后状态及输出事件逐一对齐。

这只是候选方向，实际增分尚未测得。建议原始 8192 输出上限、一次修复、300 秒绝对时限下做独立 8 目标加 6 个原有守护任务的新 C/P 对照；只增加通用提示，不叠加位映射、编译诊断、写入归属或表格验证。因首轮提示不同，不能声称同一首轮代码下的修复因果。至少 3 个不同设计类别目标提升且全部样本无回退/异常，才能考虑新的全量回归。8 个目标全部 L1→L3 的数学上界是 4.1026 个百分点，并非预计收益。

反例和未知原因必须保留：135 的题面同时写当前位与 next-state；034、053、104 的最终 RTL 表面符合题面，首次单点失配不能授权补初值；153 已正确表达训练优先级但漏异步复位，题面未给 PHT 初始化常量；155 已有饱和计数，当前行走失配不能归因于计数溢出。142、152、155 是另一个条件/输出解码方向，且属于同一题族，暂不混入首个新因子。

详细分类、证据约束和试验建议见 REVIEW.json，原始题面与 RTL 仅在被忽略的 raw_evidence 中做私有绑定。BINDING.json 固定本次复盘的实际文件摘要；它不证明任何候选实现已正确。
