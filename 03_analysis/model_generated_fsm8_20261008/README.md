# 模型生成RTL的FSM时序指导小对照

两臂都使用原common phase-P模型求解器；P仅在题面包含状态机、串行、计数器或计时器时追加通用推理检查指导。指导只提醒核对当前状态/转移输出、首末采样、非阻塞赋值及计数边界，不提供RTL模板、答案、状态转移表、测试台或参考评分反馈。最终RTL必须经既有模型回复提取/格式修补来源链验证。

固定八题、C/P各一次，16输出/最多32真实请求，8192输出token、最多一次修复、300秒求解、300/360秒外判；12000/12400秒和215分钟只是安全cap。五个输入改变首user，001/057/145为不改首请求的对照。C/P共享原技能和模型；原实际回复、编译与repair重建不变。83源冻结和10项新边界/选优检查已经AMD执行通过；100成员准备档案已AMD/E逐项绑定。尚未FIFO、无新题目成绩，不授全156/正式五样本/正式100分验收。
