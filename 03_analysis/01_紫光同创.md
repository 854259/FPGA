# 紫光同创赛题摘要

来源：`01_sources/pdf/紫光同创.pdf`；全文：`02_extracted/pdf_text/紫光同创.txt`。

## 平台

指南列出 RK3568+FPGA、盘古 676、盘古 50、SOPC 平板及摄像头/ADC 等扩展。工具链为 Pango Design Suite；CPU 题使用 `riscv32-unknown-elf-gcc` 和 CoreMark。

## 题目

1. **RV32I CPU**（PDF 文件页 9–11）：基础已要求 RV32I、至少三级流水、冲突/分支处理、UART/GPIO 和 CoreMark；高阶含 Cache、分支预测、中断和 AI 加速。新手风险很高。
2. **任意角度畸变矫正**（页 12–14）：采集/显示、二阶径向与切向映射、双线性插值；测试目标含 1080p@30/60fps、真实标定和动态角度。新手风险很高。
3. **车牌识别**（页 14–16）：FPGA+ARM/RISC-V、视频全链路、软硬通信、预处理/定位/识别，目标识别率 ≥95%。新手风险很高。
4. **SOPC 开放应用**（页 16）：AI、图像或其他创新。边界开放，只有团队已有可迁移项目时才可能降低风险。

## 板卡与支持

- 指南称提供 200 套盘古 50/676 借用，软硬协同机器视觉提供 5 套 RK3568 板，需筛选。
- CPU 题初赛不提供板卡借用，可自备或用远程实验平台。
- 链接与群号见 `02_extracted/RESOURCE_LINKS.md`。

## 当前判断

紫光固定题普遍更偏处理器架构、实时几何图像和完整识别系统，不进入当前新手短名单。
