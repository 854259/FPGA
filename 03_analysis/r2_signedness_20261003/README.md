# R2：显式位宽与符号要求的小对照

本轮按已登记的 `../codex_takeover_20261003/R2_NEXT.md` 执行，不改当前部署技能或 runtime。研究问题：通用符号检查清单是否比普通复查更能纠正算术右移错误，同时保住已经正确的符号扩展与无符号比较。

## 执行前固定的设计

- 输入为 `input/` 内三题原始题面和归档七规则候选；完整 SHA-256 与来源在 `provenance.json`，不能称当前 runtime 的新输出。云端官方题面仅比归档少首尾各一个空行，逐行核对其余完全一致；生成仍用冻结原文，判定器只容许边界换行和读文本时的行尾归一化。
- 目标 Prob115_shift18；正常守卫 Prob042_vector4；反方向守卫 Prob055_conditional。它们全部是开发题，没有未见验证集的地位。
- C=普通按规格复查，D=C加通用位宽／signed／扩展／移位语义清单。两臂相同原候选、技能、接口与预算；不传人工正确答案、探针反馈或官方判分。
- 每题固定顺序 D0、C0、C1、D1，题序115、042、055，共12调用；temperature=0、top_p=1、max_tokens=8192、单次客户端墙钟300秒；无自动重试、无选优、无续跑。
- 先验证三题独立题面探针：正控制通过，负控制必须完成仿真且语义失配；编译失败不能充当有效负控制。三题检查次数分别31、256、4096。探针以显式拼接/整数比较计算预期，未使用官方参考实现与测试台。
- 12份答案全部生成后，官方原判定及自写探针分别检查。官方系数汇总交给固定版本的 `summarize`，保留空答为L0，基础设施错误使比较无效，不缩小分母求胜。
- 晋级只要求：115的D系数均值严格大于C、两个D都过探针、两守卫D全为L3。即使满足也只进入扩大验证，不能上线或称泛化。两次重复不是两个独立任务，本轮也不是正式五样本评测。
- 模型生成前补充证据冲突门：任何样本官方L3而独立题面探针失败，暂停晋级并核对矛盾，不从两套判定里挑选有利结果；此门不改变原三项收益条件。
