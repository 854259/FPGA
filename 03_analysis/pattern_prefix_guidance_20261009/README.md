# 显式二进制序列的前缀转移提示（备选）

旧真实模型输出在一次模式检测中，遇到失败扩展后丢掉仍可用的末尾前缀。语法规则只接受题面明确写出“输入产生某些二进制值、发生于相应数量的连续时钟周期”，并绑定标量输入和原文位置；歧义、非二进制值、计数不一致、向量、非输入、显式不重叠/重启策略均不支持。没有题号或题名路由。

从模式计算“已经匹配的前缀＋下一个采样”的最长后缀前缀转移，作为首次请求的语义指导。它确实推导抽象转移，不沿用旧literal-only或“不推导行为”的声明。只在原题面规定的活动搜索阶段适用；完成后的状态、输出时延、时钟、复位和使能仍由原题面决定。不输出RTL，不读取参考实现、官方TB或判定反馈。
