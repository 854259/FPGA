# 易灵思赛题摘要

来源：`01_sources/pdf/易灵思.pdf`；全文：`02_extracted/pdf_text/易灵思.txt`。

## 平台

- 赛题一至三：Ti60F225 开发板，含 MIPI CSI-2、HDMI、DDR3、千兆网，推荐 SC431HAI 摄像头。
- 赛题四：VF-Ti60F225，含 HDMI、LVDS LCD、DVP 相机和 MIPI RX/TX。
- 工具：Efinity；软核与 MIPI/DDR/HDMI 参考设计据指南称在技术群中提供。

## 题目

1. **实时风格迁移**（PDF 文件页 4–7）：MIPI、RAW→RGB、Resize、DDR、CNN 硬件加速、RISC-V 驱动和 HDMI，基础目标 640×480 稳定 ≥15fps。新手风险很高。
2. **2D 图形渲染加速**（页 7–9）：RISC-V + BitBlt + 总线 + DDR/Framebuffer + HDMI + 双缓冲；游戏 Sprite、Alpha 和 Color Keying 是高阶。新手风险高。
3. **多模态 AI 终端**（页 9–12）：视频、红外温度、环境传感、时间对齐、TinyML、融合决策及至少两项系统拓展。新手风险很高。
4. **实时图像边缘检测**（页 12–17）：摄像头、灰度、3×3 Sobel、Line Buffer、HDMI 分屏；高阶含中值滤波、动态阈值、DDR、Canny 和目标形状。当前推荐第 2。
5. **自由选题**（页 18–20）：FPGA 必须承担真正核心功能，不接受只做简单转接/GPIO 而主要功能在外部处理器的方案。

## 明确的工期信息

指南称：对已有一定 Verilog 和基础外设经验者，赛题四基础约 3–4 周，部分高阶约 5–6 周。该条件不符合当前群聊里的零基础描述，因此只能视为成熟团队基线。

## 当前判断

赛题四是易灵思固定题中明显最适合新手的一项；如果开发板、Efinity 和采集/显示参考工程可以及时获得，它比截图中的 2D 游戏加速题更可控。
