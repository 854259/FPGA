# 完整题面表格契约：纯解析准备

`parse_prompt(prompt)` 只接收完整题面字符串，返回 admitted/abstained、题面 SHA、是否完整消费，以及每个输入组合的输出义务。没有任务 ID、候选 RTL、参考答案、TB 或文件路径参数；没有模型、EDA、网络、子进程、FIFO 操作。

当前范围是最多 4 个输入位、一个标量输出，严格消费已有的英文接口及表格模板。Kmap 按实际行列标签绑定输入位，接受完整标签排列而不假定二进制位置或固定 Gray 顺序；向量位按显式下标绑定，超界下标不会自动从一基转换到零基。声明的 don't-care 保留为 `expected=null, care=false`，不会变成零值检查。输出还保留格子的原始行列标签。

无时钟的标量波形仅接受两种完整模板：明确组合电路，或完整、一致的 simulation waveform；每个输入组合必须在题面实际出现，重复观测必须一致，时刻必须递增。083 类型会导出实际观测义务，而有限轨迹不能证明不存在题面未声明的隐藏状态。输出中明确保留这一限制。包含时钟/复位口、顺序行为文本、输入缺列、组合缺项、同输入输出冲突、额外前后语义说明或不认识的文字都弃权。不得把这个有限 parser 当作任意英语语义判断器。

本准备支持题面的完整格值表示，尚未提供 native harness、worker 接入、模型提示注入或真实修复结果。后续校准应保持首稿、8192 回复上限、一次 repair 和时间预算，独立比较首个反例与完整 cared 表反馈；先确认 parser admission，再比较反馈形式，避免将两个变化归为单因素收益。

旧单点表格反馈实际只修复 1/3，057 和 125 的部分补丁仍错误；旧 FSM feedback 1/2、全局 concise 0.70→0.65 且两题回归。这些失败不因本地 parser 测试通过而撤销。零失配但仿真超时的 082 也不因此改级。参考/TB 仍只作开发审查，不进入模型输入或该契约。

纯测试覆盖全部 24 个输入声明排列、24×24 个行列标签排列、轴交换和位序、don't-care、向量超界、完整组合波形及畸形/语义边界弃权。运行 `python -m unittest test_contract.py` 即可；本地运行用固定 Python 3.12.14。本目录只有三份源文件，收据存放在 semantic 的私有 raw_evidence。
