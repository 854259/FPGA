## 逐条处置

| # | 审计发现 | 处置 | 证据 |
|---|---|---|---|
| 1 | 空答与请求失败被移出 `pass@1` 分母（`graded = [x for x in levels if x is not None]`） | 不再自己过滤；空解经判定器得 `level=0`、`coefficient=0`，**留在分母** | `official.summarize` 直接汇总；算例 1×L3+4×空答 = **0.2** |
| 2 | `pass@5` 被改成"任一 L3"的二值指标 | 改用 pinned 口径：**该题可计分样本的最高系数**，再按题平均 | 算例 5×L1 → **0.2**；5×L2 → **0.7**（旧版都是 0） |
| 3 | 聚合层丢失 `tool_error`，环境失败被计零分 | `tool_error` 原样交给官方汇总，**单列排除**；整题全环境失败则记录不计分 | 算例 1×L3+4×环境失败 → pass@1=**1.0**，有效样本=**1**，排除=**4** |
| 4 | 缺题被静默跳过，完成性只看题数 | **逐格台账**：预期题×模式×采样 vs 实际尝试/有效/空答/环境失败/缺题；不完整返回退出码 2 | `expected_cells` / `attempted` / `graded` / `empty` / `tool_error` / `missing_tasks` / `complete` |

**另按审计第 33 行"不能静默过滤"的要求**：判定器没产出结果时标为 `tool_error`（含返回码），
**不猜等级**；且判定目录每轮先清空，避免读到上一轮的 `verdict.json`。
