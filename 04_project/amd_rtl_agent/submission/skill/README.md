# 技能包

本目录是提交方案包中的 `skill/`，包含本队智能体使用的全部提示词资产。技能包**不含任何题目答案、题目编号或参考实现**——所有内容都是通用的 RTL 编写与修复规则，适用于任意题目。

## 技能清单

| 目录 | 文件 | 加载时机 | 作用 |
|---|---|---|---|
| `rtl-generation/` | `SKILL.md` | **每次生成** | 从题面产出单个可综合 `TopModule` 时的通用约束 |
| `rtl-feedback-repair/` | `SKILL.md` | **仅在首次候选验证失败后** | 依据工具反馈做最小修复时的通用规则 |

两个技能都是**中文规则清单**，以 system 消息形式拼接到题面之前。`rtl-feedback-repair` 只在前一次候选失败、需要再一次生成时才拼入，正常一次通过时不会加载。

## 设计原则

1. **短**。生成技能只有 7 条规则、约 1 KB。本队做过两次对照实验，均显示**冗长的规则文本会降低通过率**：规则越多，模型越倾向于逐项枚举并写出推导注释，反而更容易在复杂题面上漏项。因此不轻易增加规则文本。
2. **不含答案**。技能中不出现题号、题解、参考实现或针对特定公开题的硬编码。这是赛事红线（评分细则 2.9），也是本队一贯做法。
3. **只讲形态，不讲个例**。规则只描述通用写法约束（接口服从题面、位宽与符号处理、复位语义、可综合性等），不描述任何具体电路。
4. **可度量**。技能的每次改动都必须能通过同配置配对评测量化其影响；未经评测认定的收益不做宣称。
